# ftp-plus-oauth

Native macOS cycling tools:

- **[Dual Recorder](dual-recorder):** records your Bluetooth power meter, heart-rate strap and trainer alongside Zwift and writes one FIT file per power source, for dual-recording verification. [Download](https://github.com/capceri/ftp-plus-oauth/releases?q=dual-recorder&expanded=true)
- **[FIT Studio](fit-studio):** analyse, plot and compare FIT files, and adjust recorded values by a percentage. [Download](https://github.com/capceri/ftp-plus-oauth/releases?q=fit-studio&expanded=true)

Also here:

- **[Fusion for Claude](fusion-mcp):** sets up the Fusion-Essentials add-in so Claude Desktop and Cowork can work in Autodesk Fusion, with a connection that survives Fusion restarts.
